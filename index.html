Satr سطر

A fast, local-first Markdown editor for Windows. It feels like writing, not coding.

Download for Windows View source

Windows 10/11 · x64 · the installer is currently unsigned, so SmartScreen warns on first run — choose More info → Run anyway.

Features

  • Visual (WYSIWYG) editing
  • Raw Markdown source mode (Ctrl+/)
  • Lossless saving — untouched blocks keep their exact bytes
  • Tables, task lists, blockquotes, code blocks
  • Syntax highlighting for 35+ languages
  • Math with KaTeX (inline and block)
  • Tabs, outline, find & replace, focus mode
  • Full Arabic interface with right-to-left layout

Private by design

Satr works completely offline. No account, no cloud sync, no telemetry. It only reads and writes the files you open, and never sends your documents anywhere.
