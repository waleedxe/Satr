## [0.1.0] - 2026-09-27

### Added
- Visual Markdown editor (TipTap/ProseMirror) and raw source mode (CodeMirror).
- Lossless Markdown round trips: untouched blocks are saved byte-for-byte.
- Headings, emphasis, strikethrough, code, links, images, lists, task lists,
  blockquotes, rules, tables with alignment.
- Shiki syntax highlighting and KaTeX math (inline and block).
- New, open, save, save as, recent files, tabs, drag and drop, open folder.
- Unsaved-change prompts, external change detection and deleted-file handling.
- Outline, find and replace, word/character count and reading time.
- Light, dark and system themes; font size, font family and content width.
- Focus mode, typewriter mode and optional autosave.
- Windows NSIS and MSI installers, GitHub Actions CI and release workflow.
