# دليل مشروع سطر (Satr)

مرجع شامل بالعربي لكل ما تم في المشروع، لتعود إليه في أي وقت.
آخر تحديث: 27 سبتمبر 2026.

---

## 1. ما هو سطر؟

**سطر** محرر ماركداون لسطح المكتب، خفيف وهادئ، يشبه Typora:
تكتب وترى التنسيق مباشرة، والملف يبقى ملف `.md` عادي على جهازك.

- يعمل بدون إنترنت، بدون حساب، بدون سحابة، بدون تتبع.
- الواجهة بالإنجليزي افتراضيًا، ويمكن تحويلها للعربي بالكامل.
- يدعم الكتابة بالعربي والإنجليزي معًا، والاتجاه يتعدل تلقائيًا.

## 3. التثبيت

1. شغّل `Satr_0.1.0_x64-setup.exe` (دبل كليك). يتثبت لحسابك فقط ولا يحتاج صلاحيات مدير.
2. أول مرة يظهر تحذير أزرق من ويندوز (SmartScreen) لأن البرنامج غير موقّع رقميًا:
   اضغط **More info** ثم **Run anyway**.
3. لإزالة البرنامج: **Settings ← Apps ← Satr ← Uninstall**.

**الأنظمة المدعومة:** Windows 10 و 11 و Windows Server 2019/2022 (64-bit).
يحتاج WebView2 (موجود مسبقًا في ويندوز، وملف التثبيت ينزّله إذا كان ناقصًا).

---

## 4. الملفات التي يفتحها

| النوع | الامتدادات |
|---|---|
| ماركداون | `.md` و `.markdown` و `.mdown` و `.mkd` و `.mkdn` و `.mdwn` |
| نص عادي | `.txt` |

- ويندوز يربط `.md` و `.markdown` و `.mdown` و `.mkd` بسطر بعد التثبيت (دبل كليك يفتحها).
- الترميز المدعوم: **UTF-8** (مع أو بدون BOM). الملفات بترميز قديم (مثل Windows-1256) تُرفض بدل أن تتلف.
- الحد الأقصى لحجم الملف: 64 ميقا.
- الصور داخل المستند: PNG و JPG و GIF و WebP و SVG و BMP و AVIF، من الجهاز أو من الإنترنت.
- لا يفتح: Word أو PDF أو HTML.
- ملاحظة صغيرة: نافذة "Open" لا تعرض `.mdwn` في قائمة الأنواع مع أن البرنامج يقدر يفتحها (إصلاح بسطر واحد عند الحاجة).

## 5. المميزات

**الكتابة والتنسيق**
- عناوين (6 مستويات)، عريض، مائل، مشطوب، كود داخل السطر، روابط، صور.
- قوائم نقطية ومرقمة ومتداخلة، قوائم مهام ☐، اقتباسات، خط فاصل.
- جداول مع محاذاة الأعمدة.
- كود ملوّن لأكثر من 35 لغة برمجة.
- معادلات رياضية (داخل السطر `$x$` وكتلة `$$`).
- الإيموجي مدعوم (اضغط **Win + .** لفتح لوحة الإيموجي في ويندوز).

**الحفظ الآمن**
- الأجزاء التي لم تعدّلها تُحفظ حرفًا بحرف كما كانت.
- يحافظ على نوع نهايات الأسطر (CRLF أو LF) وعلامة BOM.
- الماركداون الذي لا يدعمه المحرر المرئي (HTML، الحواشي، front matter) يبقى كما هو.
- يحذّرك قبل إغلاق ملف غير محفوظ.
- إذا عدّل برنامج آخر الملف: يعيد تحميله تلقائيًا، أو يسألك إذا كان عندك تعديلات.
- إذا حُذف الملف: نصّك يبقى ويمكنك حفظه من جديد.

**الواجهة**
- تبويبات لعدة ملفات، وقائمة الملفات الأخيرة.
- شريط جانبي: عناوين المستند (تضغط وينقلك)، ومستعرض ملفات لمجلد كامل.
- وضع النص الخام لتعديل الماركداون مباشرة.
- بحث واستبدال.
- عدد الكلمات والحروف ووقت القراءة.
- مظهر فاتح وداكن وحسب النظام.
- وضع التركيز، وضع الآلة الكاتبة، حفظ تلقائي.

**الإعدادات (Ctrl + ,)**
- اللغة: English أو العربية (الواجهة كلها تنقلب من اليمين لليسار).
- خط النص وخط العناوين (منفصلين)، مع معاينة مباشرة:
  - خطوط النظام: بدون زوائد، بزوائد، ثابت العرض.
  - خطوط عربية مدمجة: IBM Plex Sans Arabic، Cairo، Tajawal، Noto Naskh Arabic، Amiri.
  - أي خط مثبّت على جهازك.
- حجم الخط وعرض الصفحة.

## 7. الأداء (مقاس فعليًا على جهازك)

| القياس | النتيجة |
|---|---|
| حجم ملف التثبيت | 4.6 ميقا |
| حجم البرنامج بعد التثبيت | 8 ميقا |
| وقت ظهور النافذة | حوالي 0.2 ثانية |
| الذاكرة (البرنامج + WebView2) | حوالي 130–140 ميقا |
| المعالج وهو خامل | حوالي 1% |

للمقارنة (تقريبًا): البرامج المبنية على Electron مثل Typora و Obsidian حجمها 80–150 ميقا وتستهلك 250–500 ميقا ذاكرة.
لم يُختبر بعد على ملفات كبيرة جدًا (1–5 ميقا).

## 8. التقنيات باختصار

- **Tauri 2 + Rust:** الغلاف الأصلي للبرنامج. يستخدم محرك العرض الموجود في ويندوز (WebView2) بدل تحميل متصفح كامل، لذلك البرنامج صغير وسريع.
- **React + TypeScript + Vite:** الواجهة.
- **TipTap (ProseMirror):** المحرر المرئي.
- **CodeMirror 6:** وضع النص الخام.
- **unified / remark:** قراءة الماركداون وحفظه.
- **Shiki:** تلوين الكود. **KaTeX:** المعادلات.
- **Zustand:** حفظ حالة البرنامج.

التفاصيل الكاملة مع أرقام الإصدارات في `TECH_STACK.md`.

**لماذا Tauri؟** هو من أحدث طرق بناء برامج سطح المكتب: أخف بكثير من Electron، آمن بفضل Rust،
ويعمل على ويندوز وماك ولينكس بنفس الكود تقريبًا (ماك ولينكس قد يحتاجان تعديلات بسيطة).

## 9. ما تم إنجازه

- **المرحلة 0–6 من ملف المواصفات كلها مكتملة:** التأسيس، محرك الماركداون، الملفات، التحرير الكامل، الواجهة، الجودة، ملفات التثبيت.
- **بعد ذلك:**
  - تغيير الاسم إلى **سطر (Satr)** مع أيقونة خضراء جديدة.
  - إصلاح اتجاه القوائم والجداول العربية.
  - واجهة عربية كاملة (الإنجليزي افتراضي).
  - اختيار الخطوط (مدمجة + خطوط الجهاز + خط منفصل للعناوين).
  - إزالة 4 مكتبات غير مستخدمة.
- **الاختبارات:** 112 اختبار للواجهة و 15 اختبار للجزء الداخلي، و 19 تجربة آلية على البرنامج الحقيقي، كلها ناجحة.

## 11. أفكار للمستقبل

- صفحة معاينة محدّثة فيها صور الواجهة العربية.
- اختبار الأداء على ملفات كبيرة (1–5 ميقا).

- إضافة لغات واجهة أخرى (كل لغة = ملف ترجمة واحد، الخطوات في README).

- لصق الصور وحفظها داخل مجلد المستند.
- تصدير إلى HTML و PDF.
- تحديث تلقائي للبرنامج، ونسخ لماك ولينكس.

## 12. للمطورين: الأوامر المهمة

```bash
npm install                 # تثبيت المكتبات
npm run tauri dev           # تشغيل البرنامج أثناء التطوير
npm run check               # كل الفحوصات: تنسيق، lint، أنواع، اختبارات، Rust
npm run tauri build         # بناء ملفات التثبيت (النتيجة في src-tauri/target/release/bundle/)
npm run smoke:build && npm run smoke   # تجربة آلية على البرنامج الحقيقي
node scripts/screenshots.mjs           # صور للبرنامج في مجلد screenshots/
```

ملاحظات عن هذا الجهاز (Windows Server):
- Rust مثبت في `%USERPROFILE%\.cargo\bin`.
- إذا ظهر خطأ "Cannot find native binding" في Vite: أعد تثبيت `@rolldown/binding-win32-x64-msvc` بنفس إصدار rolldown.
- البناء الكامل بعد تغييرات Rust الكبيرة يأخذ 6–10 دقائق.
